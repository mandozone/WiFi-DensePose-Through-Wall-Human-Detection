Make each layer observable.

This lab documents environment configuration, container startup, route and DNS troubleshooting, and the local interface. My contribution is the deployment and integration work; the sensing application is upstream software.

Evidence boundary: a running container, loaded page, or animated heatmap does not prove a live sensor pipeline. These are historical records and include simulation.

Troubleshooting

Lessons from the build.

IssueRecorded lesson
VM DNS failureCheck resolver configuration separately from connectivity.
Compose unavailableConfirm the installed tooling and command form.
Dashboard route errorVerify the image revision, UI assets, and route.
Broken multi-line commandKeep the image name and options in one complete command.
Active-looking simulationRequire receiver records, source labels, and stale-data checks.
